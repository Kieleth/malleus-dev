Version: 0.1.0. Author approval: 2026-09-06, "go".

This is a feedback-guided repair experiment on Capture B (run-21), not another
question-withheld capture or a matched model comparison. Two independent cases
start from copies of the same accepted history. The original is never written.

## Execution and assessment

1. Freeze inputs, findings, scope and checks. Verify original replay under its
   exact runtime. Record the author decision without replacing historical runs.
2. Each producer writes one delta capture or a reasoned refusal. Return at most
   two compiler/admission diagnostics to the same session. Preserve every attempt.
   No evaluator repair and no fallback. A semantic refusal is a result.
3. Scope-check, adapt, compile and prepare against a copy of the existing history,
   then admit through the public structural helper. Retention is not admission.
   Capture-import order is not assertion time or a claim that the world changed.
4. Reopen from the resulting ledger alone. Check receipt and graph equality,
   exact preservation of the baseline ledger prefix and unrelated records, and
   retained trace for each added/replaced record. Retain failures with phase.
5. Run all thirty unchanged queries before and after. Require the before output
   to reproduce the frozen query result. Report changed answers, not invented
   new aggregate coverage scores. Have a separate source-grounded model review
   the amendments and every changed answer for support, coverage and regression.
   Human ratification remains pending. Structural admission does not certify
   source faithfulness, and a supported edge alone does not certify sufficiency.
6. Ask each producer to reassess the same finding against its amended graph.
   Record whether it requests another change. A no-change judgment establishes
   only bounded observed closure. Do not equate duplicate-ID refusal with closure.

A failure at this boundary stays a result. Send Core only a minimal reproducer
for a missing generic capability. No Core evaluation mechanism, direct graph
edit, public Re-entry API claim, automatic truth claim, or new package release.
