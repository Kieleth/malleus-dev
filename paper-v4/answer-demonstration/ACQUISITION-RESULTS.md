# The experiment's facts are now connected

Previously, the cruise answer returned only **SMARTIES cruise**. It now also
returns the **19-instrument OBS network** and **approximately 21 days of continuous
seismic recording**, with explicit links showing that both belong to that campaign.
Those numbers were already stored. The improvement is their connection, not new
measurements or a rewritten question.

One fresh Sol session proposed three links. One separate reviewer checked every
link against the complete article and supported the whole proposal. Malleus
accepted it, and rebuilding from the recorded history reproduced the same graph
and answers. All 164 previous records remain exactly unchanged.

## What changed, and what did not

| Question | Before | After, using the same query code |
| --- | --- | --- |
| Which cruise acquired these data? | SMARTIES, with no returned experiment connection. | SMARTIES connected to the network count and continuous recording period. |
| How many instruments were deployed? | The network count and OBS instrument identity. | Unchanged. This query does not yet follow the new campaign connection. |
| How long were data recorded? | Approximately 21 days of continuous recording during SMARTIES. | Unchanged. This query still does not return the instrument connection. |

Only the cruise question changes. The other 29 answers, including the qualified
evidence argument, remain byte-for-byte identical. No new complete-question total
is claimed. The separate review assessed the proposed links, not all thirty answers.
Human ratification is pending.

The three added links associate the network count with SMARTIES, associate the
recording duration with SMARTIES, and identify OBS instruments as the observing
system for that recording. The model declined a fourth permitted link because it
would describe the campaign itself as being observed with an instrument.

The review preserves important limits. Nineteen instruments in the deployed
network does not mean nineteen useful instruments or nineteen instruments recording
for the entire period. Approximately 21 days describes seismic recording, not the
duration of the cruise. The source states these acquisition facts together in
page:2:block:002; the reviewer also checked the Methods and the no-data instrument
qualification in the Figure 1 caption.
