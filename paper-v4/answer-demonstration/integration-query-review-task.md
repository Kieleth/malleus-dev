# Assess the query delta after source assessment

Continue the independent integration assessment using only the additional frozen
query packet and your source-review packet. Verify every new material identity.
Write only query-review.md in the new packet. No changes to records or earlier
reviews, no network, delegation, other runs or producer feedback.

The thirty questions, their required_semantics and query programs are fixed.
Identify exactly which question objects changed. For every changed answer,
inspect every distinct returned witness and relevant capture trace in both states.
Separate source faithfulness from coverage. A missing field is not automatically
false; a meaning-changing omission needs a named unsupported implication. A field
or path does not lose its support merely because another qualification is missing.
Only supported returned content can satisfy a requirement. Do not fill an absent
answer from the source, the integration report or an unseen graph record.

For each changed question, list all existing required_semantics with exact
before/after row or path witnesses, or an explicit reason for absence. COVERED
requires every requirement, PARTIAL a nonempty proper subset, NONE no supported
requirement. Read the whole question when interpreting each requirement; do not
change its meaning to suit the output. Do not regrade unchanged answers or invent
a new thirty-question total. Keep previous reviews intact.

Check gains and losses separately. Newly returned candidates can be irrelevant
even if their fields are faithful. Qualifiers may live in descriptions without
becoming separately typed relations or properties; state that distinction. A
support path records an author's argument, not independent physical causation.
Do not conflate local qualification with cross-block integration or infer global
completeness from a report accounting for every quantitative record.

Include a compact answer example using only supported returned content, and
remaining limitations. Identify your work as model-assisted assessment, HUMAN
RATIFICATION PENDING. This is a scoped comparison, not a validator-certified
full review or a general model-performance measurement.
