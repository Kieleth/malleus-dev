## Declared query difference

The base task's description of type-only binding does not apply to this arm.
Read the frozen question-to-program input manifest and the exact named Python
query programs it identifies. They may filter field values and traverse actual
graph relationships. No source evidence is an execution input. The manifest
binds source code and accepted surface before prospective population dispatch;
the run log must prove the ordering. Development on historical graphs is
exploratory and must never receive the prospective designation. This review
uses a binding recorded after the historical population and query execution;
it says RETROSPECTIVE_EXECUTED_PROGRAMS and makes no earlier-freeze claim.

The returned rows keep ENTITY, SUBJECT and RELATION witnesses. Additional
execution metadata names the program, candidate outcome and actual path
witnesses. These are not source-support or coverage judgments. Review is still
per distinct witness and per required semantic of all thirty frozen questions.

## Duties that need to be explicit for selective answers

1. Read the entire question when judging each required semantic. A number for
   a different substance, site, time or population cannot satisfy a generic
   bounded_quantity requirement. Units and epistemic status must apply to the
   answering value, not another record nearby.
2. Identify which fields actually answer the question, and whether they leave
   alternative values or unresolved scope. Report ambiguity in the existing
   rationale; do not choose a candidate because you know the source answer.
3. Source traces verify a returned field. If only retained prose supplies a
   requested mechanism, qualifier or relationship, that semantic is absent
   from the answer view. Use the existing absence reason and explain it.
4. Stored graph prose may carry a statement. State that its wording carries
   the answer; do not describe it as a typed relationship or graph deduction.
5. LINKED_ROWS requires a returned relation connecting the relevant answering
   records, not just any edge in the output. Several disconnected facts remain
   UNLINKED_ROWS. A bare preferred claim does not establish evidential support.
6. Judge the union of material fields projected for a witness within this view.
   A support label for a narrower historical projection does not cover new
   fields. Do not copy historical judgments or transfer labels between arms.
7. Evaluate controls by the same rule as other questions. Nonempty candidates
   do not alone establish fabrication. Empty output does not alone establish
   a correct absence claim. State what the selected source actually permits.
8. NO_CANDIDATE and NOT_EXPRESSIBLE describe this program, not the document or
   the world. Inspect the permitted source evidence to explain missing
   semantics; do not repair the query or population during review.

The query author does not perform the independent review. Review sessions
receive only the declared source surface, questions, query inputs and outputs,
provenance, this extension, the base task and a blank record. Previous reviews,
manuscript conclusions, pilot summaries and producer transcripts are excluded.
Identify model-assisted reviewers honestly. Leave Luis's ratification pending.
