## Limits that remain

The exact LAB material, fraction bases, explicit cited-work relations, geochemical
method assumptions and uncertainty population are not all represented. Removing
unsupported specificity is a faithfulness improvement, not completion of those
missing roles. The unchanged Ba90 record remains a supported bounded estimate,
not a complete method description.

The producer report's phrase "choice between Rb90 and Ba90" is ambiguous: the
source uses both methods. The reviewer records that wording problem separately
from the supported graph changes. The report is preserved, not silently edited.

SUPPORTS preserves the authors' evidential argument for a preferred hypothesis,
not independent physical causation. A six-record reconciliation cannot certify
capture completeness. The run exercises existing Core versioning and querying;
it does not demonstrate the separate general Semantic Re-entry workflow. No
missing Core capability was established, and Core and manuscript were untouched.
