OCR path, query language, extraction engine or Core evaluation contract.

Use two explicitly named read-only views of the same replayed graph:

1. Coverage view: the approved type-based query and v3 review establish which
   requested semantics are reachable and source-supported.
2. Answer view: small native graph-read programs use predicates, projections
   and actual relation traversal to return question-specific answers. Attempt
   all thirty questions; show six representative cases in the manuscript.

The second view is a proposed protocol extension, not a claim that the old
binding already answers selectively. It adds no facts or edges. Use existing
public graph methods and small shared helpers, with no new DSL or query engine.

Each answer exposes the fields that answer the question and witness record IDs.
Quantity answers retain subject, scope, unit, bounds and stated epistemic status
where requested. Traversals expose their actual edge witnesses. If several
records disagree or cannot be distinguished, return the candidates and mark the
ambiguity. An empty result means not established by this graph/query, not proof
that the source or the world contains no answer.

An answer may be carried by typed fields, explicit edges, or text stored in a
graph field. Report which. Reading stored prose is not evidence of relational
inference. Retained source prose is available to evaluation, not to fill an
answer missing from the graph.

### M4: what complete evaluation records

Reuse Fable's accepted v3 review mechanism. Do not build another scorer or
expected-answer JSON schema. Add only answer-view information the accepted
record cannot already express, as an explicit paper-owned extension if needed.

For each question record requested-semantics coverage, exact answering fields,
source support, record/edge witnesses, ambiguity, assembly and whether the
answer relies on stored prose. Report counts per question, tier and run with
their denominators. Repeated appearances of one witness are not independent
observations; one supported field does not make every field of its record true.
Also retain candidate/output counts so a broad superset is not mistaken for a
selective answer. No single aggregate quality score is required.

Evaluate all five controls. A control returning an answer triggers inspection:
wrong subject, binding leakage and unsupported assertions are separate possible
causes. An empty result alone does not validate abstention. Paraphrases should
agree on semantic coverage; record disagreements rather than forcing equality.

Review source support independently of the query author. Model-assisted review
is labelled as such. Record the independent recheck and disagreements on the
six illustrated cases; Luis's ratification is separate from those reviews and
must not be described as an independent human annotation study.

A pre-admission refusal produces no answer result. Show it in the full attempt
table, not as thirty wrong answers and not silently outside the denominator.

### M5: improve only the identified failure

represented but unreachable, missing relation/scope, source-unsupported, or an
evaluation/locator defect. Inspect census, capture and trace in this diagnostic

If the main remaining failure is a query defect, a new ontology run is not its
remedy. If a source-supported relationship or qualifier was never represented,
present one proposed producer refinement, its bounded input and its predicted
query effect to Luis. Any approved refinement is a separate condition with
before/after evidence. No question-specific facts are authored by the evaluator.

The desired result includes a scoped quantity, a genuine relational answer,
preserved hypothesis status and an honest unavailable answer. These are targets
to inspect, not grounds for discarding a poor run. No pass percentage or extra
run count is chosen after seeing outcomes.

### M6: publication boundary

Distinguish deterministic replay/query reproduction from a fresh model run,
which may produce a different ontology and graph. A private successful replay
does not by itself make the public document artifact independently reproducible.
List required private artifacts and the exact public reproduction limit; retain
the current source/PDF publication restrictions and request any new authority
explicitly. Do not replace fixed-output reproduction with a claim that rerunning
the model will regenerate the same bytes.

The manuscript reports one worked document and the tested admission/replay/query
boundary. No RAG superiority, source-truth, arbitrary-question, universal
ontology, model-ranking or general Semantic Re-entry claim follows. Core's
published evidence may be cited at its own coordinate but is not rerun here.
