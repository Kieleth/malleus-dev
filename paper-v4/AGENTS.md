# Paper task standing instructions

Read the current governing directive in paper-master-plan.md before changing an
experiment. Read answer-demonstration/SITUATION-REVIEW.md before diagnosing a
regression and THIRTY-QUESTION-RCA.md before interpreting answer totals.
Historical ledger entries and handovers are evidence, not current authorization.

Build and improve Malleus, journal the work, then write the paper when results
support it. Do not turn the development history into the paper's contribution.

Explain results in plain English first: what information became accessible,
what stayed unchanged, what remains missing. Internal labels, hashes and test
counts belong in the evidence notes, not in place of that explanation.

Keep relevant successful controls alongside failures. Distinguish historical
replication, current adoption, fixed-ontology operation and fresh end-to-end runs.
Freeze exact inputs, task, model/effort and query instrument. Verify actual
settings and model-visible delivery. Replay is not model regeneration.

Separate structural acceptance, source faithfulness and intended-use coverage.
An empty query is not proof of absent graph facts. Diagnose source, capture,
scope, links, retrieval and review separately. Do not call a multi-factor change
causal evidence. Never feed questions, answer values or old outputs into a
question-blind producer.

Luis rejects blanket exclusion of figures and tables (E-0395). Captions,
legends, figures and tables are legitimate document evidence. If the retained
reading loses layout, visual relationships or table structure, record a capture
gap; do not relabel it excluded, absent or unimportant. An interpretation still
requires exact retained evidence and locators. Do not claim a text-only reading
has captured information that requires an unavailable image or cell structure.
Future question preparation must pass next_run.py check-document-scope; frozen
historical conditions remain unchanged and must not become the next default.

Keep three responsibilities separate: evidence preserves original blocks and
source artifacts unchanged; meaning represents coherent propositions or metadata
with the context needed to interpret them; classification defines what a category
asserts about the content it qualifies. One proposition can use several blocks,
and one block can support several propositions. Preserve those links. Do not
atomize away context, broaden a category to excuse mixed content, or treat a
faithful copy as a faithful semantic representation.

Incremental amendments must mechanically preserve all accepted records except
explicit changes. Retain every attempt, refusal and unsuccessful result. No
unapproved extra sampling, hidden quotas or evaluator-authored population repair.

Before launching a capture or repair, check that its permitted changes and
feedback can achieve the stated outcome. Surface any conflict before launch;
never silently widen scope or promise full repair under incompatible restrictions.
For every acknowledged in-scope gap, record a source-backed resolution, an
already-represented finding with exact fields/links and evidence, or a specific
unresolved reason naming the missing evidence, capability or permission. An item
inventory, locator, generic NO_CHANGE explanation or passing structural check is
not substantive reconciliation. A finished attempt can leave the wider objective
incomplete. Report that distinction explicitly. Preserve honest uncertainty and
unaffected knowledge; removing information just to pass a gate is not improvement.
This completion rule does not authorize retries, stronger admission policy or
new experiments, and does not turn a valid partial import into a protocol failure.

Core owns generic protocol/runtime/skills and Small Shop. This task owns paper
capture, queries and evaluation. Send Core only domain-neutral capability defects
with pinned reproducers. Do not edit Core or move shared refs from this task.

Every new version of the review protocol is exercised by at least one full
graph cell of the record condition before the paper claims it (Luis,
2026-09-12: "we need one for each new version of the protocol"). A protocol
version that has only judged a baseline surface, or that exists only as a
derived layer beside frozen records, is not yet the paper's protocol.

The resume point for this front is the most recent
`handover/<date>-paper-session-handover.md`; read it before changing an
experiment, together with the governing directive in paper-master-plan.md.

A control question is not verified by its overall wording. Before a question
set is frozen, assess every absence-control element against the whole selected
reading. A partly answerable absence control refuses. Paraphrase controls are
instead checked against their positive question. Run evaluation-v4/control_screen.py
on the exact reading, questions and identified assessor's record; the freezer
requires this record. Code enforces identity, closure and consistency, not
natural-language entailment or absence. Uncertainty refuses rather than becoming
an assumed absence. This has been got wrong twice, in set A (fixed at
E-0346) and in set B, the second time by an author deliberately blind to the
first lesson. A ledger entry alone does not prevent recurrence. A validator
prevents bypassing the recorded assessment, not an assessor's semantic error.

Use experiment-v4/NEXT-RUN-CHECKS.md before another launch. Frozen per-cell
preparation scripts are historical evidence, not templates. Keep the declared
model identifier exact; do not strip aliases or infer execution identity from a
producer's own output. Count reviewed witnesses from returned rows, separately
from all records visited while tracing them. Missing declared private fixtures
fail the active test gate rather than silently skipping an evidence check.

Future graph semantic reviews must pass next_run.py check-review-context with
the accepted ontology and every import's exact source bytes, not just the
compiled field list. Read those definitions and record any undefined distinction.
An evidence block is a layout unit, not necessarily one coherent proposition.
Text matching proves neither its category nor its modality. Before claiming new
information, check all earlier returned fields, including prose. Keep original
judgments when a later audit exposes a mistake or an unresolved rule; never turn
an interpretation change into a capture gain.

The paper does not claim that Malleus wins single-document accuracy against a
model reading the same document in one window. Report the observed fresh-context
reference result, not a proven maximum. Cite published degradation findings
within their model/task scope; they do not prove deterioration of this baseline
or a Malleus remedy. Distinct witness units do not support a comparative precision
claim. Total session tokens minus document length are not reasoning tokens.
Claim nothing about cross-session memory improvement that has not been measured.

A claim about every reported run must be checked against every run it names.
Never support a cohort-wide absence with one control's inventory. The manuscript
test now inventories evidence predicates across all reported graphs and retains
run-26's two SUPPORTS links as positive controls. Missing links for a particular
argument are not zero use of evidence links throughout the graph.
