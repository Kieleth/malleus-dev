## Defect and guardrail

authoring functions. Canonical serialization reordered the maps, so rebuilding
the same declared variant changed its bytes. The initializer's complete-byte
comparison refused both positive cases before any append. The first run therefore
had 21 passes and two failures, not a partially initialized success.

The dedicated map-serialization regression failed before repair. The supplier
builder now canonicalizes role order before lowering, covering both source and
policy maps without changing their values. The same regression and actual supplier
initialization then passed. This produces a new identified program; it does not
rename any retained bytes. No Core code or definition changed. The earlier
same-insertion-order determinism test remains as a control, not the whole law.

pytest-fixture name shadowed by a parameter; explicit fixture registration fixes
that binding, and the executed gate verifies discovery. The RED commit freezes
that corrected fixture registration, not a byte-identical copy of the earlier
