## Cause 1, the evaluator's: eleven absences are type sets that do not reach the record that carries the answer

Under harness v4.12 a type set lists record types; the binder makes one ENTITY_NO_SUBJECT case per listed type (records whose subject slot is absent), one SUBJECT case per listed subject-bearing type and listed subject type pair, and RELATION cases. A claim whose subject is a geologic feature is reached only if the feature type is listed beside the claim type. The overseer wrote CQ-T4-01's set as the claim type alone. The export carries 124 claims, 63 with a subject (53 GeologicFeature, 3 GeologicBoundary, 3 RockSample, 2 Campaign, 1 ResearchSource, 1 SoftwarePackage); the question returned the 61 subject-less ones and none of the claims that state the preferred explanation. CQ-T4-01 is NONE on that alone, and the same omission removes claim_subject from CQ-T4-02 and CQ-T4-03 and the mechanism from CQ-T5-01. Three more absences are plain omissions of the carrying type: no instrument type in CQ-T1-05, no dataset or count type in CQ-T2-02, no observation type in CQ-T2-04 (two items).

The closure check (E-0198) cannot catch this: it guards subtypes of listed types, not the subject types a subject-bearing type needs. The catalogue lesson of run-21 (leave out types the question does not ask for) pushed the sets small; the v4.12 subject mechanics punish small sets on exactly the questions about claims. Eleven of twenty absences, and the only NONE among positive questions, are this.

## Cause 2, the producer's modelling: seven NOT_MODELLED

No slot for a journal acceptance date (CQ-T1-03, two items); a persistent identifier split across two blocks and declared nothing assertable in the continuation (CQ-T1-04); no relation or field ordering two methods (CQ-T2-02); no evidence record or relation joining an observation to the mechanism it supports (CQ-T5-01, CQ-T5-05); no comparison relation between two contents (CQ-T5-02). Four of the seven are relations between records the graph holds side by side. This producer declared 1 RELATION_ABSENT gap where run-21 declared 88, and it formalized 31 relations to run-21's 26, so it is not a producer that avoids relations; it is one that did not model evidence and comparison as relations.
